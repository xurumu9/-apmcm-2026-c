# 候选模型与决策记录

## 模型选择

先可解释基线，再据题意覆盖、分组验证、校准、误差、不确定性和可识别性增加复杂度。小样本、稀疏组合和重复实验限制参数数量。模型名称本身不是优越性证据。

| 模块 | 基线与理由 | 扩展与验证 |
|---|---|---|
| Q1 检验 | 中位数/IQR、分布图；Kruskal–Wallis 与两两置换检验，覆盖两类非参数方法；Holm 校正 | Dunn 事后检验、效应量/区间。先核实独立性，必要时受限置换；不对结构缺失特征机械做三组检验 |
| Q1 分类 | 共同完整特征上的正则化多项 Logistic，便于解释 | 浅树/随机森林作对照。折内预处理，报告 macro-F1、balanced accuracy、混淆矩阵；可行时日期分组验证，不以 F02 缺失直接编码类型的完美准确率作主结论 |
| Q2 退化 | 分别描述三指标，透明权重联合，等权为参照；简单参数曲线与单调平滑比较 | 其他生态权重/几何聚合。检查有界性、残差、距离层验证和权重敏感性，解释近距离非单调及约束代价 |
| Q2 范围 | 求阈值交点并报告区间/界限 | 核实层级后按真实实验单位重采样；不默认 300 行独立，不挑孤立远端交点；无交点报告界限或不可估计 |
| Q3 总体 | 成对描述、组层级 Logistic，控制情境/距离/群体规模 | 正则化或贝叶斯分层；音轨效应在可识别时纳入。按 expID 验证，控制完全分离，不把对照接近为零解释为真实概率必为零 |
| Q3 组合 | 八状态多项模型，共同协变量和 control 基准 | 收缩多项或多变量 Bernoulli。检查概率和、校准及稀疏状态；独立二分类仅作边际对照，不默认行为独立 |
| Q3 强度 | 是否响应+正值条件模型，正计数用零截断模型，持续时间用 Gamma/对数正态 | 过度离散时零截断负二项。先核实零值和冲突，不照搬参考脚本结论 |
| Q3 潜伏期 | 响应概率+响应者条件潜伏期 | 有窗口/删失依据后才考虑 AFT 或生存模型；无响应不填零，不编造删失时间 |
| Q4 效能 | 明确认知与行为的条件关系后定义指标 | 比较聚合、权重、阈值、响应比例。行为模型已有距离效应时再乘保真度可能重复计入损失；无法标定时限定为情景指数 |

任务与截止时间统一见 [TEAM_PLAN.md](TEAM_PLAN.md)；本文件只记录方法与证据。

## 决策台账

2026-11-27 补充：结构判别规则处于**试验中**，使用 F02 和 PulseRate 是否有记录分别识别 tv、mod，其余判 flat；表内一致率及局限见 [复现记录](../experiments/reports/q1_structure_rule.md)。它依赖已提供的结构信息，不能作为未知音频的独立准确率；共同完整特征分类仍是必要对照。是否用于论文由队伍判断。

2026-11-27 补充：用户倾向先用 F02 记录状态判 tv，再对其他样本使用六项共同特征和脉冲记录状态训练 CART。该方法在按日期留组的第二阶段折外预测中合并第一阶段规则得到 103/108；第一阶段和模型结构是在探索同一数据后固定，不能作为独立测试或未知录音准确率。完整设置、对比和边界见 [CART 前置规则实验](../experiments/reports/q1_cart_fixed_gate.md)。状态：试验中，仍需团队审阅及敏感性分析。
