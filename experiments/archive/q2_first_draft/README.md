# 早期 Q2 探索归档（不作为当前方案）

本目录归档 P2 在 2026-11-26 至 2026-11-27 期间产生的旧探索：三个脚本、两份工作说明、十个汇总表和三张图。它们由 AI 生成或整理，未经队伍独立审核；不得声称已经代表最终模型。

这些结果使用分段线性/对数距离插值，与 P2 随后选定的单调回归主要候选不同，数值不应混用。例如 tv 在阈值 0.7 下约 15.83 m 是旧线性插值规则的结果，不是当前单调候选结果。原有草稿仅供追溯。当前候选内容请见 `experiments/reports/q2_candidate_notes.md`、`experiments/reports/q2_weight_scenario_notes.md` 和 `src/python/q2_candidate_models.py`。

早期使用的逐行独立 bootstrap 区间已撤回，不包含在此归档中。归档中的权重/模型情景范围不应称为统计置信区间；`results/10_paired_playback_context.csv` 是描述性统计，其自然叫声与对照的距离经常不同，不能解释为控制距离后的因果效应。

为避免上传原始附件，此处不包含原始 Data02–11、原始 R 参考脚本或 Supplementary4 PDF，也不包含工作目录缓存。历史脚本若需执行，需要将比赛原始 Data02–11 复制到本目录的 `data/`；该目录仍被忽略。代码及汇总图表保留原样；模型及赛事规则由队伍核查。
