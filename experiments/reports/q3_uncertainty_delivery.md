# Q3 阶段 6：综合不确定性与交付

2026-11-27。用户授权启动阶段 6。以下规则在运行前明确，不依据本轮区间宽窄继续调模型。

## 固定模型与区间口径

八状态 C=1 多项 Logistic、实际正计数门槛＋零截断 NB2、各行为窗口门槛＋零原子＋截断 Log-normal type 模型，复用阶段 1–4 的实现和参数。该选择基于已经探索的数据，故本阶段仅评价固定模型/分析规则条件下的参数不确定性，不包含先前选模型过程，不宣称独立确认或无偏最优。GEE 的稳健参数区间保留阶段 2 来源，不混为 Bootstrap 区间。

主分析 500 次 expID 配对整组 Bootstrap；敏感性为 500 次自然叫声音轨整簇 Bootstrap，同轨道对应的所有 call/control 对共同纳入。每次重新拟合预处理和全部固定组件，重复抽到的组赋独立 Bootstrap 簇与实验对标识，保留原来源标识。音轨标识是否共享底层录音仍未核实；此分析不是新建随机效应模型，也不自动涵盖日期依赖或真实新录音泛化。

输出 95% 逐点 percentile 置信区间（非同时带）；不同条件的 lower/upper 不要求求和为 1。组合点概率与每个 Bootstrap 概率向量必须求和为 1。缺事件、数值失败、参数触界、缺少训练类别逐项记录，区间报告实际有效次数；若不足 500，明确条件于成功拟合，不声称无条件覆盖。稀有 001 组合仅一个观测，Bootstrap 缺类的零概率不是已识别的结构零。

未来实验预测与上述置信区间分表：每次 Bootstrap 每条件再抽 100 次观测过程。次数模拟正值门槛和截断 NB2，包括零；潜伏期先抽无响应/零点/正时间，非响应时间保持缺失并另存类别码。潜伏期预测区间条件于窗口内响应，包含即时零点，报告模拟响应样本数；不把无响应赋为 60。组合的未来类别给出 Bootstrap 混合概率下 95% 概率集合，不对类别代码做数值分位数。所有预测范围均为模型依赖的近似范围，未获外部覆盖验证。

次数与各行为时间的未来抽样分别用于边际预测，不能把同一抽样序号横向拼成完整实验的联合轨迹。八状态联合未来类别由组合概率另行描述；事件定义和目标人群不同的记录不强行拼接。Bootstrap 参数重复仍使用同一组数据重采样，保留共享样本引起的估计相关性。

36 条件保持原 n=8、刺激前次数=0、4 类型×3 情境×3 距离，附人口/正事件支持及范围。HeadsUp 与原组合边际共享；Vocal/Approach 排除冲突后各自重拟合门槛；实际计数正值概率与 Vocal 标记区分。持续时间沿用阶段 5 的 72 条不可识别接口，不生成正式真实时长点估计或区间。

新增参数区间仅针对可直接比较的 NB2 alpha 和三行为 log 时间标准差 sigma；不混合不同重复中标准化中心/尺度变化后的回归系数。GEE 保留阶段 2 的 expID 聚类 sandwich 参数区间，并注明来源及方法。缺少事件、数值失败与参数触界分列：触界但优化成功的约束估计仍保留，不能据此声称参数已充分识别。

## 实际运行与验收

正式运行 `results/q3/q3_stage6_full_20261127T133654Z/`，独立实现 `src/python/q3_uncertainty_delivery.py`。预先做过每单位 5 次的 smoke 流程检查，目录名称和 metadata 明确标记 smoke/full_analysis=false，不作为科学区间交付；正式模型参数和 Bootstrap 规则未依据该检查结果调整。

原数据包含 139 个 expID 配对组与 28 个自然叫声音轨簇。两个单位各 500 次，合计 1,000 次完整重采样；每次重新拟合 5 个组件，5,000 项组件结果全部有效。每条件每单位模拟 50,000 次未来边际观测，响应条件时间的实际有效模拟数另列，最少为 expID 553 / 音轨 559。

4 个次数触界重复均为 alpha 达到预设下界 exp(-8)=0.00033546，即近 Poisson 边界，保留为约束估计而非删除。警告是 SciPy/Boost 离散逆分位数的括根警告：expID 第 487 次、音轨第 100/255/390/480 次（编号从 0 起），发生于 `predict_count` 的中位数库调用。逐个复现后，未来计数抽样未出现该警告，其实际抽样逆 CDF 不等式检查通过；进一步独立从截断均值恢复底层 mu，全部 36,000 个已保存次数中位数均满足 hurdle CDF 的中位数条件。记录原警告，不将有限返回值自动等同于数值可靠。

八状态稀有 001 在 expID/音轨 Bootstrap 中分别有 172/174 次训练缺类，按沿用接口赋零概率。没有把这些零当成识别出的结构零，也不把成功拟合 500 次解释为该状态已可靠估计。

- `parameter_confidence_intervals.csv`：8 行 alpha/sigma 区间；`gee_parameter_intervals.csv` 保留阶段 2 稳健 log-odds 参数区间并标记非 Bootstrap。
- `bootstrap_expID.npz`、`bootstrap_natural_track.npz`：完整重复参数结果及未来边际抽样。`resampling_manifest.json` 保存每次抽组来源，`bootstrap_diagnostics.json` 保存全部 5,000 项组件的事件数、缺类、收敛/触界/警告，`bootstrap_summary.csv` 给计数汇总。

Q4 主分析先筛选 `resampling_unit=expID`；`natural_track` 是另一套敏感性，不能把两套重复行累加。组合表的 event 定义是原始 HVA 标记，对应 `analysis_population_id=combo_all_v1`；完整人口定义见阶段 1 `population_definitions.csv`，其他 estimand 的事件/人口在表内分别命名。计数的 q_positive 不等于原 Vocal 标记概率；Vocal/Approach 潜伏期门槛也不替代全人口组合边际。

下游传播不确定性时，优先使用同一单位、同一重复下的完整概率向量/组件估计，保持共享数据引起的参数相关性。不能独立从各格置信区间抽数再拼成“联合分布”；也不能把边际的未来抽样横向拼成一条 HVA/次数/时间联合行为轨迹。若整合 Q2，跨数据集依赖与联合抽样假设须另行说明，不按来源行号连接。Npenguins 是观察数量，群体响应概率不能直接当个体响应比例；人数估计仍需额外假设。

独立验收 `verify_q3_uncertainty_run.py` 已通过并写入 acceptance.json：

1. 核对所有抽样种子与抽组清单、重复簇配对、数据及辅助实现哈希、38 项原附件未变。
2. 核对每个重复的概率和、三部分质量、单调 CDF、CDF(60)=响应概率、HeadsUp 与八状态边际一致。

4. 核对次数均值恒等式与全部次数中位数的独立逆 CDF 条件；核对未来类别集合的概率质量和时间中非响应 NaN。
5. 各代表条件的组合/次数/潜伏期点估计与阶段 2/3/4 逐项一致；72 条持续时间估计和区间仍留空，没有以 0 补不可识别值。
