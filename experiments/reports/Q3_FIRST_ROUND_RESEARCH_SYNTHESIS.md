## 1. Response Pattern

### 1.1 研究问题、估计对象与数据

研究群体在播放后 60 秒内是否有记录响应、发生哪些行为组合，以及这些记录如何随播放类别和条件变化。H=抬头、V=发声、A=接近，C=(H,V,A) 为 000–111。

目标是 P(C=k|x)、p_any=1−P(000|x) 和由八状态边际化得到的 p_H/p_V/p_A。二元 GEE 另估计原标记任意响应的边际概率与 log-odds 关联。两者不是同一个预测任务的不同评分。

主组合人口为 combo_all_v1，保留全部 278 行和原 H/V/A 标记；不因潜伏期或 Duration 冲突删行、不用 Q1 分类率修正类型。任意响应 108 条，H/V/A 分别 68/81/23；三行为可重叠。来源：[S1-P]、[R0 的观测响应][R0-O]与[组合频数][R0-C]。

### 1.2 模型与选择依据

[C0] 的 fit_combo/predict_combo 为 L2 多项 Logistic C=1、加性主效应。联合归一化保证组合概率一致；比在小样本中增加大量交互更适合作为基线。收缩能稳定数值，但不会补足稀有类别的观测。

[C12] 预定 C∈{0.25,1,4} 的有限比较：外层 expID 五折、配对自然音轨五折、日期留组；选 C 时只在外层训练集内做 expID 三折。音轨/日期路线的内层仍按 expID，评价的是这一既定流程在未见音轨/日期上的表现，不是内层也按音轨/日期选择的流程。固定 C=1 与内层选择全部并列，不能用外层得分给“最终最优模型”贴无偏标签。

GEE 使用 Binomial/logit、expID 聚类和稳健 sandwich 标准误，Exchangeable 主对照、Independence 敏感性。没有拟合随机截距；GEE 的任意响应概率不替代八状态联合分布。

### 1.4 Bootstrap 不确定性

S6 固定 C=1，在实验对与自然音轨两个层级各重采样 500 次；组件各成功 500 次。001 分别有 172/174 次训练缺类，零概率不能解释为结构不可能。原 S2 各外层路线也存在一次真类未见于训练，有限 Log-loss 含 sklearn 数值截断约定；此限制不因 Bootstrap 成功而消失。

组合概率逐点 95% 区间宽度中位数为 expID 0.1251、音轨 0.1216，最大 0.4859/0.5486。完整 576 行区间与同重复相减的 432 行 call−control 差值保留所有组合，不只选择不跨零结果。72 个未来类别预测集合是模型混合概率集合，不是置信区间或外部校准的覆盖保证。来源：[S6-B]、[S6-C]、[S6-D]及[区间报告][S6-R]。

### 1.5 能支持与不能支持的结论

能支持：样本中自然叫声和对照的响应及组合分布存在明显观测差异；加性联合模型在既定 expID 验证中优于训练频率参考，可作为概率基线；有限调参尚未带来稳定增益。

不能支持：任何声学感知能力已由不响应排除；三类叫声在所有情境下有确定优劣；对照接近真实概率严格为零；距离系数能直接给出听觉阈值或通信半径；关联具有充分因果解释。GEE 的 expID 稳健区间未同时解决音轨/日期的全部依赖。稀有状态、宽区间和代表条件外推使精细组合解释必须保留限制。

### 2.4 Bootstrap 与科学结论边界

S6 次数组件两个单位各 500 次有效；alpha 点估计 0.432048，expID 区间 [0.059336,0.669086]、音轨 [0.068526,0.647868]。分别 3/1 个约束估计触及 alpha 下界，1/4 次重复含分位数警告；既有验收记录了额外逆 CDF 核对，不能隐去边界敏感性。[S6-B]、[S6-P]、[S6-R]

例如 mod/after/50m、N=8、刺激前次数=0，总次数期望 1.922677：expID 均值 CI [0.730001,3.882357]，音轨 [0.626344,3.435087]；未来一次计数范围分别 [0,11]/[0,10]，包含零与观测变异，不能把均值 CI 当预测区间。本格原人口及正次数人口均标为联合支持内。[S6-I]、[S6-F]

**S5 的持续时间工作模型没有本轮 Bootstrap 区间。** S6 保留 72 条真实持续时间估计/上下界为空的接口；不能借用潜伏期 sigma 区间给 Duration，也不能把 R0 的 200 次几何目标历史区间当作编码已核实的真实时长区间。

能支持：计数适合区分正值发生与正值次数的模型；NB2 在既定两条验证路线比 Poisson/截距参考更有依据，但仍有低估。持续时间能支持的是记录分布、边界冲突与选择敏感性描述。

不能支持：可靠的真实时长类型排序、窗口外完整持续时间、未核实的逐条删失界限；A=0 对照能证明永不接近；总次数等于响应企鹅人数或群体规模可作为实际暴露时长。持续时间的语义不确定性不能靠模型收敛或更多重采样消除。

## 3. Response Latency

### 3.1 问题、估计对象与人群

研究播放后首次记录到群体行为的启动时间，不是每只企鹅平均反应时间。目标为行为在 60 秒内发生的概率 p_b、响应者中的记录零比例 pi0、正时间条件分布 G(t|0<T≤60,x)、含零响应者的条件算术均值/中位数，以及窗口内累积响应概率。

| 行为主分析 | 总记录 n | 响应事件 | 记录零 | 正时间 | 排除的标记/时间冲突 |
|---|---:|---:|---:|---:|---:|
| H | 278 | 68 | 9 | 59 | 0 |
| V | 274 | 81 | 0 | 81 | 4 |
| A | 273 | 23 | 0 | 23 | 5 |

来源：[S1-P]、[S4-P]、[S4-OOF]。不是三个等大小总体；V/A 是可评价记录人口。原标记全部保留的敏感性人口均 278，事件 V/A=81/23；时间证据口径均 278，事件 85/28。无响应不赋为零或观测时间 60；记录零也不自动等同于生物学精确即时反应。

### 3.2 模型、接口及选择理由

窗口主模型的三部分质量为 1−p_b、p_b pi0、p_b(1−pi0)，正密度为 f(t)/F(60)。H 主门槛使用八状态边际；V/A 在各自排除冲突人口单独拟合 C=1 Logistic。pi0 为训练响应者记录零比例，不对零取对数、不加任意常数。

正时间固定比较截断 Log-normal/Weibull，type 小模型、完整 x 对照与截距参考；总负对数似然加 10/2×斜率平方和。**type 只限制时间部分为类型主效应，主模型的窗口响应门槛仍含完整 x**。截距参考则连门槛也使用训练事件频率。小模型降低稀疏 A 数据的参数负担，并不保证充分识别。

AFT 对照仍为同两分布：连续部分在非即时人口拟合，正时间为事件、无响应行政右删失 60，排除记录零；以训练全人口零比例 r 恢复原子，响应概率 r+(1−r)F(60)。H 连续人口全数据为 269；V/A 为 274/273。该概率不套用窗口模型 p_b。[C34] 的 fit_time/event_probability/predict_time 是这一差别的直接代码依据。

|---|---:|---|---|
| H | 0.602419 | [0.498366,0.662894] | [0.503108,0.667464] |
| V | 0.804731 | [0.663751,0.917948] | [0.646849,0.906311] |
| A | 0.673847 | [0.419596,0.829365] | [0.452308,0.842111] |

具体条件的 p_b、三部分质量、均值/中位数和 CDF 区间见 [S6-I]。未来时间范围见 [S6-F]，条件于窗口内响应且包含记录零；每格响应模拟数单列，两个单位最少 553/559。非响应通过另列概率与 NaN 时间表示。来源：[S6-P]、[S6-M]与[实现的抽样分支][C6]。

能支持：窗口内响应与条件时间需要分开解释；截断 Log-normal 小模型相对既定候选有可保留的联合预测证据，能给出带条件、支持范围与模型依赖区间的初步时间预测。

不能支持：所有实验的无条件平均等待时间、窗口外长期生存/永不响应比例、精确零反应机制或三个行为完整联合时序。对照 A 未观测正时间，相关模型条件时间来自其他单元和收缩，不因有区间就成为直接观测证据。没有外部预测覆盖验证，稀疏 A 和类型/情境正事件支持不足继续限制解释。

## 4. 模块关系与 Q4 输入

### 4.1 共享概率必须同时匹配事件与人群

| 连接 | 是否可直接共享 | 第一轮实际口径 |
|---|---|---|
| 八状态 → any/H/V/A 边际 | 是 | 原标记、全 278 行；必须从同一联合向量求和 |
| 八状态 H → 主窗口 H | 是 | 同为 H 原标记、全 278 行；包括相同重复的 Bootstrap 边际 |
| 八状态 V/A → 主窗口 V/A | 否 | 主窗口人口已排除 4/5 冲突，分别 n=274/273，单独拟合门槛 |
| 八状态 V/A → original_flags 潜伏期敏感性 | 是，限该版本窗口模型 | 原事件/全 278 行相同；不是主排除版本或时间证据版本 |
| 八状态 p_V → 次数 q | 否 | 81 个原标记阳性与 85 个实际正次数不是同一事件 |
| 窗口 p_b → AFT | 否 | AFT 在非即时人口拟合并另恢复零原子，概率由 F(60) 产生 |
| GEE p_any → 替换八状态 P000 | 否 | 另一二元模型，不直接构造原八状态联合分布 |
| 原响应门槛 → 筛选后 Duration 条件工作均值 | 否 | Duration 人口 275/266，不是原 278；编码与选择机制也未解决 |

数学上只有在事件、人群与条件一致时，p×条件均值才是该目标下的全期望。次数 q m_+ 已满足明确的计数门槛口径；不能改成 p_V m_+。潜伏期无响应没有观测时间，不把 p_b×条件时间均值命名为全体实验平均等待时间。来源：[S1-P]与 [C34] 的各分支。

### 4.2 三类不确定性及结果不能直接拼接的情况

1. 同一 Bootstrap 参数重复共用整组样本，可保留估计相关性；但 [C6] 分别模拟次数和各行为的未来边际结果，同抽样序号不代表一次真实实验的联合行为轨迹。
2. 95% percentile 是固定模型与规则条件下的逐点 CI，不是同时带，也不含先前模型选择不确定性。概率点向量/每次重复应和为 1；各类别的区间端点不必分别和为 1。
3. GEE sandwich 参数区间、alpha/sigma 参数 CI、条件期望 CI、未来计数/时间范围和未来类别集合不能相互替代。R0 的 200 次历史 Bootstrap 与 S6 的 500 次修订目标也不能拼成 700 次。
4. expID 主分析与音轨敏感性是不同簇假设，不把重复行当更多样本、不把两套区间平均。日期评分已有敏感性，但 Bootstrap 未联合覆盖日期、音轨和实验对的全部依赖。

### 4.3 Q4 使用建议与交付边界

以 S6 正式目录为当前入口，保留旧版与科学综述的来源链：

- [组合概率][S6-C]：按 CallType×Context×Distance，使用 expID 主分析的原 HVA 向量及区间；音轨另作敏感性。整体响应可由 1−P000 得到；行为权重应由 Q4 的明确科学目标确定。
- [强度与潜伏期长表][S6-I]：严格筛选 outcome/estimand、event_definition_id、analysis_population_id、单位及 resampling_unit，不能将所有 probability 字段视为同一“响应概率”。持续时间 72 行不可识别项不得填零或代入正式效能公式。
- [未来边际预测][S6-F]：用于描述单次实验可能结果，不用于替代均值/概率的 CI；群体响应概率也不能直接乘 Npenguins 推断响应人数，人数仍需额外比例假设。
- [同条件模型差值][S6-D]来自同一次重复相减，不能由两端 CI 简单相减。非线性效能传播应读取 [expID 完整重复][S6-N1]或[音轨完整重复][S6-N2]中相同重复的整向量，不独立抽各格 CI 再拼接为联合分布。
- 检查 distance_support、joint_support、conditional_joint_support 和事件数。36 条件在组合人口仅 5 插值、20 边界、11 外推；仅距离在观测范围内不保证 N=8、刺激前次数=0 的联合支持。mod/after/150m 仍有明确距离外推。
- Q2/Q3 没有确认的逐行连接键，只按类型、距离和情境接口整合；Q3 已含距离关联，再乘保真度可能重复计入衰减。跨数据集依赖、阈值、权重和因果/情景含义需由 Q4 单独说明。当前数据不识别任意噪声变化导致的真实行为概率变化。

### 5.3 可选模型改进，先设问题与停止条件

1. **次数均值/尾部校准**：由 1.1511 对 1.0300、N≥10 低估支持。先核对高计数记录、按组校准及影响度，再至多对现有 NB2 的少量预设惩罚/表示作受限对照；同划分、训练内选择，与简单参考并列。没有稳定收益就保留基线。
2. **事件/音轨依赖表达**：第一轮 GEE 只针对总体响应，整簇 Bootstrap 不等于层级模型。独立层级核实且样本支持时，才考虑小规模依赖结构敏感性；不直接给八状态加大量随机效应或交互。
3. **时间表达的简约性**：full 时间协变量未稳定胜过 type；保留小模型优先。只有在相同人口、目标和评分分解下出现明确残差结构，才安排少量有声学/行为依据的扩展，不开启树、神经网络或大网格搜分。
4. **持续时间模型**：只有编码与逐条观察界限明确后，才在原 Gamma/Log-normal 路线内决定精确、受限或删失似然；S5 的无界记录工作分布不自动升级为正式模型。

第二轮采用条件应同时包括：事件/人口/观察机制一致、同组外目标上有稳定收益、校准和支持范围可解释、复杂度与有效事件数相称。任何数值收益都不能替代数据语义证据；软件测试、优化成功和验收 JSON 仅证明其检查范围内的实现与算术一致，不证明生态机制、因果解释或外部区间覆盖。
