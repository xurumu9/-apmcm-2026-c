## 1. 目标与第二轮完成标准

研究不同声音刺激和实验条件与企鹅群体响应的关系，按 Pattern、Intensity、Latency 给出科学结论。第一轮已提供可复现基线，第二轮重点是：确认目标与观察机制、解释调整后关联、定位预测不足，并明确哪些定量结果能用于 Q4。

| 模块 | 第二轮必须回答 | 主交付形式 |
|---|---|---|
| Response Pattern | 哪些声音与总体响应或具体行为组合有关，差异有多大？ | 概率差、区间、目标人群、支持范围及结论段 |
| Response Intensity | 哪些声音与更多发声有关？能否可靠比较行为持续时间？ | 总次数期望差、门槛/正次数分解；真实持续时间可识别性结论 |
| Response Latency | 哪些声音与更高窗口响应概率或更短响应时间有关？ | 主要：调整后的 60 秒窗口响应概率差；单独报告各自响应者条件中位数差、分解评价及结论段 |

每个结论采用同一结构：“在【人群、窗口与条件】下，【刺激与参照】的【估计对象】差为【点估计及区间】，在【验证/口径敏感性】下【稳定或不稳定】，因此支持【相应证据层次的结论】；不能推出【具体限制】。”

证据不足时必须回答“目前无法可靠区分”，并区分：样本/区间精度不足、预测尚不可靠、数据语义导致目标不可识别。不能把这些情况写成“已经证明相同”，也不以算法更复杂作为完成标准。

### 2.3 描述、调整关联与因果解释分开

| 证据等级 | 允许的论文表述 | 需要保留的说明 |
|---|---|---|
| 描述统计 | “样本中某播放条件的响应率/记录分布较高” | 分母、配对/簇结构、原始条件分布差异 |
| 调整后统计关联 | “模型调整所列条件后，某声音与较高概率/次数或较短条件时间相关” | 模型、人群、共同支持、区间与敏感性；控制几项变量不等于消除全部混杂 |
| 设计支持的因果解释 | 仅在逐因素核实设计、时间顺序、识别假设及适用人群后使用“导致/提高”等 | 明确目标因果对比、分配机制、残留效应/干扰、未测混杂及选择问题；不因实验名称或配对本身而自动升级 |

声音类型、Distance、Context、Npenguins 分别评估，不能共享一个笼统“可作因果解释”的标签。调整变量还要核查时间顺序：某变量在本次刺激前测量，不必然意味着未受此前刺激影响；不能机械控制可能受处理影响的中介或选择变量。

即使声音分配可随机化，E[N|N>0] 与 E[T|响应] 仍条件于刺激后的响应状态，不同声音下响应者可能不同，不能直接解释为“同一群体被该声音使得更强/更快”。整体 E[N] 与窗口累积响应概率、响应者条件量分别报告；当前默认不做条件响应者因果识别，也不新增相应复杂模型。

交付一张“因素—设计证据—目标人群—可用表述—未识别假设”表，允许最高证据等级因因素或估计对象不同而不同。

## 3. 共用比较口径与评价规则

### 3.1 先定义比较对象和目标人群

1. **主要比较基础为对应实验对**：Flat、Mod、TV 分别使用其 48/33/58 个 expID 下的 Control，不把全部 139 条 Control 当成每类的原始匹配对照。第二轮正式实现先生成可追溯映射表，含 expID、两侧来源行、自然叫声类型、条件和音轨；不得仅按行顺序或 PlaybackTrack 名称配对。
2. 本次已只读核实 Data02：139 个 expID 均恰有一条 call 和一条 control，Control 的 CallType 全为 control，278 个来源行无遗漏/重复；两侧 Context/Date 一致，Distance 不同的 90 对、Npenguins 不同的 2 对。因此“配对”不是全部条件一致，也不证明顺序随机或底层生物学身份已核实。
3. **原始配对差**：在类型 a 的对应实验对 E_a 中，平均两侧实际观测结果之差。概率目标使用事件指示，次数使用实际次数；它描述实际配对播放条件下的差异，包含两侧条件不同的影响。不能称为已隔离声音类型的效应。
4. **调整后的配对目标比较**：仍以 E_a 中对应两侧的观测协变量为参考，每个实验对等权、每侧各半权。对同一参考 x 分别预测 a 与 control，再平均差值；形式为每对 1/2×{[m(a,x_call)−m(control,x_call)]+[m(a,x_control)−m(control,x_control)]} 的均值。它是以对应配对人群为目标的模型调整关联，不是“call 在自己的 x、control 在另一 x”的预测差。m 按模块取窗口概率、次数期望或单列的条件时间量；只有模型实际包含的条件才可称已调整。原始配对差与调整差分别报告，不混合含义。
5. 主模型仍可沿用 v1 的全分析人口拟合，不要求为三个类型各重建模型；这里限定的是主要比较来源与参考人口。先仅根据协变量/来源结构检查支持，再算结果。沿用双方类型×Context 单元退化维度凸包与原数值容差；若某对任一参考侧不在双方共同支持内，调整后主比较整对排除，保留完整配对并报告原因。原始全配对描述不因模型支持筛查而被覆盖。
6. 各模块保持 v1 的模型分析人口不变，另列比较所需的完整可评价配对人口。主 Latency 的 H/V/A 模型人口仍为 278/274/273 行；按原排除规则，两侧均可评价的配对分别为 139/135/134 对（V 的 Flat/Mod/TV=46/33/56，A=47/33/54），这些数量尚未扣除共同支持筛查。不能用未配对的剩余单侧补足主配对比较，也不把完整配对筛选后的估计误称为原全人口结果。条件时间比较还必须保留各声音下实际响应者选择的限制，不要求“两侧都响应”来暗改目标。
7. **统一参考人口标准化仅为补充**：如在不同刺激间使用统一的观测参考人口，须预先定义其来源、模块可评价规则、权重及共同支持，单独命名。它不再代表各类型对应的配对人群。直接自然叫声两两排序仍为次要问题，仅在相同参考人口与共同支持下报告，不从三种不同配对人口的差值推出排名。
8. 共同支持为空或过薄时，明确该目标无法可靠比较。全配对人口的外推调整结果如保留，单列为模型敏感性，不悄悄取代主比较。原 36 条件继续作为 Q4 场景接口，不替代配对分析或统一参考人口；第一轮仅 5 条件为联合支持内部、20 边界、11 外推。每个结论都命名对应人口。

所有主比较的分组验证、Bootstrap 和整组影响分析均保留 expID；音轨重采样把对应所有 call/control 对共同纳入。模块规则使某侧不可评价时，完整配对比较的人口变化和选择风险明确列出。以上不改写第一轮人口或结果，不以配对结构自动赋予因果含义。

Context、Distance、Npenguins 的解释：在有共同支持的范围内，Context 相对 after；两个连续变量预定用相应模块观测人口的第 25 与第 75 百分位作摘要对比（分位点只依赖协变量），其余观测协变量按参考人口标准化。若改变协变量后无共同支持则不估主对比。连续变量的摘要对比不是声学阈值或因果效应；原模型系数和范围图作为辅助解释，不作大规模切点搜索。

## 4. Response Pattern 研究安排

### 4.1 固定问题和模型

原 HVA、278 行。使用第一轮八状态 C=1 联合模型；GEE 作为总体响应关联对照，不用其 p_any 替换联合 P000。有限 C 选择第一轮没有稳定收益，本轮默认不再扩展分类器或交互。

### 4.2 具体分析与产物

1. 并列原始响应/组合频数、对应实验对的原始差与调整后的配对目标概率，不把原 searching 高响应率当作调整后效应。

## 5. Response Intensity 研究安排

### 5.1 发声次数：先定位低估来自哪里

以全部 278 行、85 个实际正次数为人口，q=P(N>0)、m+=E[N|N>0]、E[N]=q m+ 分开。主模型保留 NB2，Poisson 与截距参考保留。第一轮总体均值实际 1.1511、NB2 折外预测 1.0300，P(N≥10) 实际 0.0180、预测 0.0119，是本轮诊断依据。

先做以下固定诊断，不引入新模型：

- 门槛：q 的折外校准、二元评分，按类型/情境及日期/音轨查看支持和偏差；小单元只描述，不以噪声排名。
- 正值：响应为正的记录上检查条件均值误差、离散/尾部、原有 ≥5/≥10 阈值；不按事后最好表现另选阈值。
- 总体：比较 q m+ 的均值校准和尾部预测，定位是门槛、正值分布还是少量高计数簇驱动。影响分析整组剔除/重估只作敏感性，不能以高影响为由删除真实高计数。
- 科学比较：按第 3.1 节以三种声音各自对应的 Control 作主要比较基础，总次数期望差为主；q 差与正次数条件均值差用于解释来源，统一参考人口标准化另列补充。后者属于不同响应者组成下的条件关联。

### 5.2 受限改进的触发与停止

只有诊断显示可重复的正值部分问题、且原始记录无明确编码错误时，才比较现有 NB2 正值斜率惩罚 λ∈{0.25,1,4}，λ=1 为原基线；门槛 C=1、特征及家族固定，不与其他参数做组合网格。选择仅在外层训练数据内按 expID 三折进行，以整个计数的合并预测负对数评分评价，保留所有候选与参考。该可选实验不是本轮必做项，也不预判必然改善尾部。

λ 的精确定义沿用 [fit_count 实现](../../src/python/q3_count_latency_models.py)：正值部分最小化 `−Σ_{i:N_i>0} log f_ZTNB2(N_i|mu_i,alpha) + (λ/2) Σ_{j=1}^{p} beta_j²`，`log(mu_i)=beta0+z_i' beta`。似然是训练正记录的**总和，不是平均**；β0 截距不惩罚，alpha（以 log(alpha) 优化）不惩罚，所有非截距类别/连续变量斜率均进入同一平方惩罚。λ 仅是这一正值部分的系数，不是门槛 Logistic 的 C 或离散参数。

每个内层训练折在全部该折计数记录上拟合特征变换，再取该折正记录拟合截断部分；外层重拟合只用外层训练数据。类别编码基准沿用 v1，连续 Distance/Npenguins/VocalNcallsBefore 用该训练折均值/标准差标准化，测试/验证侧只应用训练变换。门槛仍使用自己的训练侧变换和固定 C=1；不得用全数据标准化、只改 λ 定义却沿用旧得分，或随每折样本量暗中把总和改成平均。

补充 alpha 与数值稳定性诊断：沿用第一轮 beta 界 [-12,12]、log(alpha) 界 [-8,5]、三个固定 log(alpha) 初值 0/−2/1 及原 L-BFGS-B 设置，不新增 alpha 搜索网格。各候选各折记录正记录数、优化终止/收敛、有限目标值、alpha、触界方向和固定初值的一致性；跨 expID/日期已有版本及必要 Bootstrap 报告 alpha 的分布、近 Poisson 下界频率、极端值和有效/失败次数。诊断若显示变化，应区分重采样/样本构成、约束边界和数值问题，不靠扩大参数界限或静默删失败重复来消除提示。触界不是自动失败，也不证明充分可识别。

第一轮 S6 的 alpha 下界触及为 expID 3/500、音轨 1/500；次数分位数警告分别 1/4 次，已有额外核查。这是增加稳定性诊断的依据，不是预先认定需要换家族。惩罚候选仍只有 {0.25,1,4}，收敛/触界信息与同口径预测评价共同判断；日期留组结果先按第 3.3 节复用。

修订须同时考虑同口径组外评分、总体/尾部校准、稳定性和复杂度；某个指标单独改善不足以采用。若方向不稳定或诊断指向信息/数据不足，停止调参，保留 NB2 并明确偏差。不得宣称有限比较已彻底证明模型能力或信息不足。

### 5.3 持续时间的条件分支

- **未核实编码**：第一轮审计与受限记录模型作为现有证据，必要时补充来源核查；不重复搜索工作模型，不出真实持续时间类型排名或正式区间。最终回答“目前不能可靠判断声音类型与真实行为持续时间的关系”，说明不可识别原因。
- **获得可靠编码证据**：先确定是精确时长、结束时间戳还是删失编码及逐条界限，记录变更依据；再在原 Gamma/Log-normal 路线制定对应支持/似然，另存独立实现与结果。具体界限未知前不提前指定 60−latency 为删失界限，也不默认将全部边界值改写。

产物：次数门槛/正值/总体诊断、标准化次数差与区间、稳健性与有限对照（若触发），以及“哪些声音与更多发声相关、真实持续时间能否比较”的最终结论。必须区分响应更常发生与响应后次数更大。

## 6. Response Latency 研究安排

### 6.1 先拆开两种科学回答

主人口沿用 H278、V274、A273。第一轮窗口 Log-normal type 是默认候选；响应门槛仍含完整协变量，时间部分只有 type。分别回答：

1. **主要估计对象**：按对应完整可评价实验对与共同支持人口调整后的 60 秒窗口响应概率差，某声音相对其对应 Control 高/低多少个百分点？门槛模型包含完整 x，但调整关联不自动等于因果效应。
2. **单独的条件性估计对象**：在各自声音/Control 下观察到的窗口响应者中，首次响应的条件中位数是否更短、差多少秒？它条件于各自响应者，不是同一群体的时间因果变化，也不要求先把两侧均响应的实验对筛出来。

两条不能合并成“该声音使企鹅反应更快”。同时输出含记录零的响应者条件中位数/算术均值、正时间条件量及固定 1/5/10/30/60 秒累积响应概率；累积概率同时包含响应机会与启动速度，不解释为纯粹速度。

时间部分目前只含 type，因此其条件时间差只能称为该类型时间结构下的条件关联，**不能称为调整了 Context、Distance、Npenguins 等全部实验条件后的时间效应**。完整协变量门槛的调整不会自动传递成时间部分的调整。保留现有小模型，不因两部分协变量不一致就为 23 个 A 事件盲目增加参数；模型结构差异如实作为解释边界。

### 6.2 预定诊断

利用现有 OOF，在相同评价人口分解单条负对数评分：

- 无响应：−log(1−p)；
- 记录零：−log(p)−log(pi0)；
- 正时间：−log(p)−log(1−pi0)−log(g(t))。

分别汇总门槛、零点、正密度对联合评分的贡献，保留各部分分母；不存在零事件的行为不伪造零点条件评分。并列响应校准、固定时间点累积概率校准、响应者条件中位数 MAE，以及预定简单参考。

第一轮 H/A 条件中位数 MAE 未胜截距参考，V 改善很小；因此联合 NLL 优势不能预先归功于时间部分。分解后如仅门槛有可靠收益，最终结论必须如实限定，而不是继续加模型直到出现时间优势。

原标记全部保留、排除冲突、时间证据版本同时给共同可评价人口与各版本人口结果；分数更好不证明哪种语义真实。正零点 pi0 的估计及所有选择保持训练侧。

### 6.3 模型对照边界与最终结论

不默认重做模型搜索，保留 type 小模型、既有 Weibull/full/截距参考。AFT 为不同观察假设的敏感性，不把它较差的现有评分解释成删失机制被证伪。只有确需研究机制时，才另行明确匹配人口、可用协变量、零点与估计对象的受限比较；即使协变量相同，AFT 将响应与时间绑定、窗口模型允许独立门槛的结构差异仍应说明。

产物：联合评分分解、时间点校准、主要的调整后窗口概率差与单列的响应者条件时间差、支持与口径敏感性，以及一段回答“哪些声音更易在窗口内引发响应、哪些条件时间可可靠区分”的科学结论。配对基础按第 3.1 节，已有日期/额外口径范围按第 3.3 节；不能预设需要重做全部日期分析。对照接近没有正时间直接观测、A 仅 23 个事件；借助收缩的预测明确注明，不能仅因区间窄就定为可靠类型差异。

### 10.3 R2-2：Response Pattern

**工作**

1. 基于 R2-1 类型对应的实验对，给原始总体/边际/八状态频数和配对概率差；两侧条件不同的原始差不解释为纯声音效应。

4. 先复用 S2 的分组 OOF/日期结果与 S6 可用重复。若新配对参考预测/区间不在旧文件中，才用相同固定模型与对应重采样补充必要预测；这是新增统计量所需计算，不是新分类器搜索或重跑所有第一轮实验。
5. 完整报告点估计、同重复差值区间、支持与稀有 001 的限制，形成 Pattern 的科学结论段。

**拟交付**：`pattern_observed_paired.csv`、`pattern_adjusted_contrasts.csv`、`pattern_supplementary_standardization.csv`（有适用人口才输出）、对应图表与 `Q3_ROUND2_PATTERN.md`。

**验收/进入 R2-3 的条件**

- 音轨/日期证据按真实组件列出，未用系数或训练分数替代组外评价。

**工作**

### 10.6 R2-5：证据触发的有限改进及必要验证

**进入时先列“分支—证据—执行或不执行理由”，不默认把下表都运行。** 没有触发项时，本阶段交付跳过理由和模型保留结论即可。

| 分支 | 触发依据 | 可做范围与停止条件 |
|---|---|---|
| NB2 正值正则化 | R2-3 发现可重复的正值问题，原始记录无明确编码错误 | 仅 λ={0.25,1,4}；门槛 C=1、家族、特征、界限/初值不变。训练内标准化、总似然＋λ/2 斜率惩罚、截距/alpha 不惩罚；内层 expID 三折选择，外层原划分验证。报告 alpha 收敛/触界/稳定性；无稳定收益即保留 λ=1 |
| 正式 Duration | 获得可核实的编码与逐条观察界限 | 先明确精确/结束时刻/删失语义，再在原 Gamma/Log-normal 路线制定相容实现；语义未解决不执行。禁止用拟合好坏选编码 |
| 额外日期/观察机制敏感性 | 确实缺少对应版本结果，并能回答 R2-2～4 提出的实质可靠性问题 | 说明目标/人口/变量/结构差异，只补必要缺口；不重复已有日期分析，也不扩大模型家族或把 Pattern 音轨证据推广到其他模块 |

实际修订必须保留原候选、同外层划分、同人口及完整结果；只有数据定义有可靠新证据时才另建规则版本并给共同可评价比较。置信区间只覆盖实际重做的流程；固定家族区间不更名为包含选择不确定性。对新统计量/实际变更只做必要的重复拟合与区间传播，沿用 v2 重采样单位和失败披露规则。

**拟交付**：`limited_branch_decisions.md`；实际运行时才增加 `limited_experiment_matrix.csv`、候选/参考组外比较、参数稳定性及必要不确定性结果。没有执行的分支不得出现伪造数值或“已验证”标记。

**验收/进入 R2-6 的条件**：每个执行/跳过都有第一轮或本轮诊断依据；采用/保留/不可识别有明确理由；不能仅靠总分、某一个类型或某一有利日期决定。实际变更已回写相应模块报告的科学结论，原基线及失败/触界结果仍可追溯。

### 10.7 R2-6：最终科学结论与 Q4 交付
