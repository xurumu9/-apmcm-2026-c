## 三个科学问题的回答

### Response Pattern

在各自有共同支持的配对参考人口中，Flat/Mod/TV 相对对应海浪声 Control 的总体响应概率调整差为 **40.25 [28.84,52.34]、39.82 [27.08,53.29]、47.02 [36.26,57.71] 个百分点**（expID逐点95%区间）。两套重采样方向相容，主要伴随发声与抬头边际增加。八状态保留，001仅一条不能支持细致机制解释。

这些主要比较人口分别30/20/39对，不直接构成三类声音排名；统一人口补充为另一个103观测行目标，仍未建立可靠类型排序。Context/Distance的GEE区间不能可靠区分方向；群体规模有负向调整关联，但不是个体响应效应。原始差、调整关联、实验设计可支持的因果解释必须分开。

### Response Intensity

以实际次数为事件，三类声音相对各自 Control 的群体总次数期望调整差为 **1.178 [0.764,1.652]、1.706 [0.830,2.706]、1.481 [1.060,2.000] 次/播放**，音轨敏感性方向相容。更高次数同时涉及正次数机会和正值条件量；条件量涉及不同响应者组成，不能推为同一群体强度因果增加。

模型折外预测仍低估总体均值/高尾：expID实际/预测均值1.1511/1.0300，≥10实际5条，预测概率0.0119低于0.0180。门槛加权误差与正值误差都参与，少数高计数组贡献明显。λ=4的微小NLL改善未伴随稳定综合收益，保留λ=1。**目前不能可靠判断哪种声音对应更长的真实行为持续时间**，因为Duration观察编码不可识别，记录工作模型不是正式真实时长证据。

### Response Latency

主要回答“60秒内是否响应”，而非把不响应赋为60秒。H、V三类声音均与更高窗口概率相关；A中Mod/TV为正，Flat区间跨零：Flat/Mod/TV的A调整差为 **3.70 [-0.81,9.90]、14.12 [4.54,23.71]、12.78 [4.31,22.91] 个百分点**。

**没有可靠证据支持自然声音使响应者普遍更快。** H-TV条件中位数约多0.625秒（探索性区间[0.079,1.383]），并非更短；其他H/V对比多不能可靠区分。时间部分只有type，不能称全条件调整时间效应。A-Control没有响应者，其条件时间完全借用模型，不能作实测速度比较。

联合评分主要由响应门槛获益，H/A条件时间MAE未胜截距，V改善很小且日期不维持；较好联合NLL不等于较好时间预测。条件中位数、算术均值、正时间量与CDF分别列出，不相互替代。

## 模块接口与证据边界

| 量/接口 | 本轮规则 |
|---|---|
| Pattern H 与 Latency H窗口概率 | 相同事件、人口、C1模型和重复，已逐项核对；共享一次，不当独立重复证据 |
| Pattern V/A 与排除冲突Latency V/A | 人口/门槛不同，不能直接拼接；尤其Flat A区间差异不能挑有利者替换 |
| 计数q与VocalYesNo | 前者N>0，85正次数；后者标记81，不能互换 |
| q、m+、总体次数 | 逐参考行q·m+后平均；不能乘两个已平均的量 |
| 窗口概率与条件时间 | 响应机会与各自响应者的时间量，不能拼成无条件“更快”；正时间type不自动获得门槛的全变量调整 |
| Duration | 真实时长不可识别，无正式数值/区间；不能靠拟合或成功运行选编码 |
| 主要/补充/场景人口 | 类型对应支持配对为主，103行统一人口为Pattern补充；S6的36场景仍是场景，三者不同 |

原论文提供call/control随机播放顺序与情境内随机轨道抽取的设计说明，优于“没有随机化信息”的旧表述。但实际顺序/间隔/身份、底层录音映射和60编码仍未充分核实；不能由回归控制推出排除了所有混杂或残留。自然音轨标识28与论文方法数26存在差异，操作性音轨敏感性不是底层身份独立性证明。详见R2-1来源表。

各模块依旧是探索性分析，无新独立测试集；逐点区间没有多重比较或选择流程覆盖保证。音轨Bootstrap不等于音轨OOF，日期/音轨验证只在原实际存在的组件上引用。原始描述、调整关联与受实验设计假设限制的因果解释保持分开；软件验收不证明科学普遍有效。
